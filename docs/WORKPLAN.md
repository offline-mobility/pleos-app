## 1단계. 기반: 화면 밖에서도 계속 동작

| 번호 | 작업 | 완료 기준 |
|---|---|---|
| 1.1 | 송수신·중계 엔진을 화면(ViewModel)에서 분리해 포그라운드 서비스로 옮김 | 앱을 다른 화면으로 내려도 수신·중계 계속, 상단 알림 표시 |

| 1.4 | 네트워크 보안 설정 | 평문 HTTP 차단, 외부 노출 컴포넌트 최소화 |

## 8단계. 통신이 살아 있을 때

| 번호 | 작업 | 완료 기준 |
|---|---|---|
| 8.1 | 구조 서버 (`server/`) | 구조 요청 수신·검증·합치기, 요청 제한, 테스트 |
| 8.2 | 재난 자동 인식 | 긴급재난문자를 재난 모드로 분류, 앱에서 "행동요령 보기" 제안 |
| 8.3 | 대피소 미리 받아두기 | 주변 대피소를 기기에 저장, 통신이 끊겨도 방향·거리 표시 |
| 8.4 | 온라인 구조 요청 | 보낸 요청을 서버로도 전송, 끊겨 있으면 복구 시 자동 전송, 서버의 주변 요청 표시 |
| 8.5 | 구조 상황판 | 토큰으로 보호되는 지도 화면 |
| 8.6 | 통신 상태 표시 | 상단 "통신 연결됨 / 통신 끊김" |
| 8.7 | 민방위대피소 | 전국 데이터를 서버에 묶어 두고 주변 검색, 면적 기준 수용 인원 |
| 8.8 | 상황에 맞는 대피소 | 공습은 민방위대피소, 지진은 옥외대피장소, 한파·폭염은 쉼터를 먼저 표시 |
| 8.10 | 대피소 앱 내장 | 전국 민방위대피소 1.7만 곳을 앱에 넣음(빌드 때 서버 스냅숏 복사). 통신이 한 번도 안 돼도 안내 |
| 8.11 | GPS 대비 | 마지막 위치 기억, 불가능한 이동(1km 넘게, 시속 250km 넘게)은 교란으로 보고 사용자에게 확인, 위치를 못 잡으면 시·도·시·군·구 직접 고르기 |
| 8.12 | 경보 단계를 차가 실행 | 공습경보: 전조등·미등·안개등·실내등·독서등 소등과 복구. 화생방경보: 창문 닫기, 내기순환, 공조 끄기. P단에서만, 에뮬레이터 Virtual Console로 확인 |
| 8.13 | 대피소 길 안내 | 대피소 상세의 `길 안내`가 NaviHelper `requestRoute`로 차 내비에 목적지를 넘김. 에뮬레이터에서 경로 안내 시작 확인 |
| 8.14 | 주변 시설 | 약국·종합병원(건강보험심사평가원 2026-09-30), 편의점(소상공인시장진흥공단 상가정보 2026-09-30)을 종류별 파일로 앱에 넣음(`npm run update-facilities`). 종류별 목록, 상세, 길 안내. 주유소·충전소·급수시설은 data.go.kr 키 입력 후 추가 |
| 8.15 | 첫 화면·행동요령 정리 | 9칸 순서(주변 시설, 연료·전력 부족, 고립됨 / 응급 환자, 추위·저체온, 화생방 / 식수·식량 필요, 약 필요, 도움 필요), 행동요령 9개(전시 4단계 + 대설·한파, 호우·침수, 지진, 산불, 태풍·강풍), 버튼 이름 `행동요령` 고정, 머리말 버튼과 지도 칸 정렬 |
| 8.9 | 재난문자 선별 | 진행 중인 재난만 표시, 캠페인·종료 안내·생활 안내 제외 |
