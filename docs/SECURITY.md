## 3. 남는 위험

- **주변 구조 요청 조회:** `/api/reports/nearby`는 인증 없이 반경 10km 안의 구조 요청 위치를 돌려준다. 소리 신호로 이미 주변에 공개된 정보이지만, 좌표를 바꿔 가며 넓은 지역을 긁어 갈 수 있다. 요청 횟수 제한으로 늦출 뿐이다.
- **재난문자 지역 판단:** 가장 가까운 대피소 주소로 시·군·구를 정하므로, 경계 근처에서는 옆 지역 문자가 보이거나 빠질 수 있다.

- **위조 신호:** 소리 신호에는 인증이 없어 누구나 가짜 구조 요청을 보낼 수 있다. 통신이 없는 상태에서 쓸 수 있는 공통 인증 수단이 없기 때문이다. 앱은 중계 횟수를 제한하고, 서버는 여러 차량의 보고가 일치하는지로 신뢰도를 판단한다(GATEWAY_API.md).
- **위치 공개:** 보낸 위치는 주변 차량 누구나 받을 수 있다. 구조를 위한 의도된 동작이며, 보내기 전에 확인 화면에서 끌 수 있다.
- **조명 제어 권한:** `CONTROL_CAR_LIGHTS`는 Pleos App Market 사전 승인 대상이다. 승인 전 실차 배포 시에는 해당 권한을 빼고 소리 신호만 쓴다.
- **공조 제어 권한:** `CONTROL_CAR_CLIMATE`, `CONTROL_CAR_SEATS`도 차량 제어 권한이라 같은 승인 절차를 거칠 것으로 본다(미확인). 권한이 없으면 난방 아끼기 항목이 화면에 나타나지 않는다.
- **난방 복구:** 난방 아끼기 도중 앱 프로세스가 강제 종료되면 시작 전 설정으로 복구되지 않는다. 히터는 낮춘 설정 온도로 켜진 채 남고, 사용자가 직접 조절할 수 있다.
- **버틸 수 있는 시간 추정:** 차량이 바깥 온도와 히터 종류를 알려 주지 않아 바깥 영하 15도·저항식 히터 기준으로 짧게 잡는다. 실제 시간과 다를 수 있어 화면에 "추정"으로 표시한다.
- **QR 위조:** 누구나 같은 형식의 주소를 만들 수 있다. 소리 신호와 같은 수준의 위험이며, 서버의 요청 횟수 제한과 여러 보고의 일치 여부로 다룬다. 페이지를 여는 것만으로는 전송되지 않는다.
