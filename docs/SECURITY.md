# 보안·개인정보 점검

점검일: 2026-11-11, 대상: release 빌드 0.1.0

## 1. 데이터 흐름

| 데이터 | 어디서 | 어디로 | 보호 |
|---|---|---|---|
| 마이크 소리 | 차량 마이크 | 앱 메모리 안에서만 해독 | 저장·전송하지 않음. 듣는 동안 상단 알림 표시 |
| 내 위치 (GPS) | 위성 GPS | 사용자가 보내는 메시지에만 포함 | 확인 화면에서 "내 위치" 표시와 끄기 제공. 약 40m 격자로 줄여 보냄 |
| 받은 구조 요청 | 다른 차량 신호 | 기기 안 보관함 → (통신 복구 시) 구조 서버 | AES-256-GCM, 안드로이드 키스토어 키(추출 불가), 백업 제외 폴더, 최대 7일·500건 |
| 차량 ID | 앱 시작 시 무작위 8비트 | 신호 프레임 | 차량·사람과 연결되지 않고 앱을 다시 켤 때마다 바뀜 |
| 설치 ID | 무작위 UUID | 구조 서버 요청 | 차량·사람과 연결되지 않음 |

## 2. 점검 항목

| 항목 | 결과 |
|---|---|
| 외부 노출 컴포넌트 | 시작 화면(MainActivity)만 노출. 서비스는 비노출. androidx ProfileInstallReceiver는 시스템 전용 DUMP 권한으로 보호 |
| 백업 | `allowBackup=false`, 데이터 추출 규칙에서 클라우드 백업·기기 이전 모두 제외 |
| 네트워크 | 평문 HTTP 차단(`usesCleartextTraffic=false`, 네트워크 보안 설정), 시스템 인증서만 신뢰, 서버 주소는 `https://`만 허용, 리다이렉트 따라가지 않음 |
| 비밀값 | 앱 안에 API 키·비밀번호 없음. 서명 키와 비밀번호는 저장소에 올리지 않음(`.gitignore`) |
| 로그 | 위치·메시지가 담긴 로그는 디버그 빌드에서만 출력. release 빌드에서 앱 로그 0줄 확인 |
| 디버깅 | release `debuggable=false`, R8 코드 축소·난독화 |
| PendingIntent | `FLAG_IMMUTABLE` |
| 입력 검증 | 신호 해독은 RS 오류 정정 + CRC-8로 깨진 신호 차단. 무음·단일음은 해독되지 않도록 화이트닝 적용. 보관함 파일의 잘못된 줄은 버림. 서버 전송 JSON은 숫자·정해진 값만으로 구성 |
| 증폭 공격 | 가짜 신호를 대량으로 보내도 차량마다 분당 6회까지만 이어서 전달 |
| 조명 오작동 | P단에서만 송신, P단을 벗어나면 즉시 중단하고 원래 조명으로 복구 |
| 권한 | 실제 쓰는 권한만 선언: 마이크, 위치, 알림, 포그라운드 서비스, 인터넷, Pleos 조명 조회·제어·주행·에너지·TTS |

## 3. 남는 위험

- **위조 신호:** 소리 신호에는 인증이 없어 누구나 가짜 구조 요청을 보낼 수 있다. 통신이 없는 상태에서 쓸 수 있는 공통 인증 수단이 없기 때문이다. 앱은 중계 횟수를 제한하고, 서버는 여러 차량의 보고가 일치하는지로 신뢰도를 판단한다(GATEWAY_API.md).
- **위치 공개:** 보낸 위치는 주변 차량 누구나 받을 수 있다. 구조를 위한 의도된 동작이며, 보내기 전에 확인 화면에서 끌 수 있다.
- **조명 제어 권한:** `CONTROL_CAR_LIGHTS`는 Pleos App Market 사전 승인 대상이다. 승인 전 실차 배포 시에는 해당 권한을 빼고 소리 신호만 쓴다.
