# 화면 설계

대상: 전쟁으로 차를 타고 피난하다 도로가 막혀 오래 정차해 있는 40~60대를 포함한 운전자·동승자. 통신은 끊겨 있고, 긴장한 상태에서 처음 보는 화면을 다뤄야 한다. Pleos 앱은 P단에서만 화면을 쓸 수 있어, 정체로 멈춘 시간이 이 앱을 쓰는 시간이다.

## 1. 원칙

| 원칙 | 적용 |
|---|---|
| 한 번 보고 알 수 있게 | 화면마다 할 일은 하나. 첫 화면은 "보내기", 오른쪽은 "받은 신호" |
| 누를 것은 크게 | 주 버튼 높이 96dp(약 15mm), 보조 버튼 72dp 이상. 버튼 사이 간격 16dp 이상 |
| 글자는 크게 | 제목 34sp, 본문 24sp, 보조 정보 20sp 이상. 160dpi 차량 화면에서 제목 높이 약 5mm |
| 쉬운 말, 짧게 | "송신·중계·SNR·홉" 같은 말을 쓰지 않는다. 이름만으로 뜻이 분명하면 설명 줄을 달지 않는다 |
| 차와 같은 모양 | Pleos 시스템 화면(설정, 앱 목록)과 같은 무채색·각진 모양을 쓴다. 차 화면 안에서 따로 놀지 않게 |
| 색은 빨강 하나 | 위험과 경고에만 빨강. 나머지는 흰색·검정·회색 |
| 색만으로 전달하지 않기 | 모든 메시지에 아이콘과 글자를 함께 붙인다 |
| 실수해도 되돌릴 수 있게 | 메시지를 누르면 바로 보내지 않고 확인 화면을 띄운다. 보내는 중에는 언제든 멈출 수 있다 |
| 행동 버튼은 아래 | 확인·멈추기·닫기 버튼은 화면 아래쪽에 둔다 |

## 2. 색과 모양

Pleos Connect 시스템 화면을 기준으로 한다(설정, 앱 목록, 공조 화면을 에뮬레이터에서 직접 확인).

- 흰 바탕에 검정 글자. 시스템이 야간 모드면 검은 바탕에 흰 글자.
- 모서리는 각지게(0). 칸과 버튼은 1px 회색 테두리.
- 주 버튼과 선택된 항목은 검정으로 채우고 글자는 흰색. 나머지 버튼은 흰 바탕에 테두리.
- 누를 수 없는 버튼은 회색 바탕에 회색 글자.
- 토글은 켜면 검정, 끄면 회색. 손잡이는 흰색으로 같은 크기.
- 고르는 버튼 여러 개(앞 / 뒤 / 앞뒤)는 테두리 하나로 묶고 고른 것만 검정으로 채운다.
- 아이콘은 단색. 아이콘 뒤에 동그란 색 바탕을 깔지 않는다.
- 색은 빨강 하나만 쓴다: 받은 신호 중 위급한 것의 아이콘, 통신 끊김, 에너지 부족, 듣기 꺼짐, 재난문자 표시, 행동요령의 "하지 마세요"(✕)와 "차에서 조심할 점"(!).

| 토큰 | 밝은 화면 | 어두운 화면 | 쓰임 |
|---|---|---|---|
| page, canvas | `#FFFFFF` | `#000000` | 바탕, 칸, 시트 |
| surface | `#F2F2F2` | `#1C1C1C` | 받은 신호 영역, 낮은 면, 누를 수 없는 버튼 |
| line | `#C8C8C8` | `#4A4A4A` | 테두리 |
| ink | `#000000` | `#FFFFFF` | 제목, 아이콘, 채운 버튼 |
| body | `#424242` | `#D0D0D0` | 본문 |
| mute | `#767676` | `#9E9E9E` | 시간, 보조 정보, 꺼진 토글 |
| urgent | `#D7282F` | `#FF5A5F` | 위험·경고 (유일한 색) |

코드에 남은 accent, safe, help 같은 이름은 쓰임을 읽기 쉽게 둔 것이고 값은 위 무채색·빨강으로 묶었다. 그라데이션, 글로우, 그림자는 쓰지 않는다.

## 3. 화면 구성 (가로)

```
┌───────────────────────────────────────────────────────────────┐
│ 어떤 상황인지 알려주세요       [받은 신호 5] [행동요령] [설정] │
│ 가까이 위치한 차량에 신호를 보낼 수 있어요                     │
├──────────────────────────────────┬────────────────────────────┤
│ ┌────────┐┌────────┐┌────────┐   │ 주변 지도        대피소 목록 ›│
│ │주변 시설││연료·전력 부족││ 고립됨 │ ┌[새 신호]──────────┐│
│ └────────┘└────────┘└────────┘   │ │ 응급 환자 3명   방금  ││
│ ┌────────┐┌────────┐┌────────┐   │ │ 북동쪽 약 250m        ││
│ │추위·저체온││저전력 모드││응급 환자│ │ [닫기][받았다고 알리기]││
│ └────────┘└────────┘└────────┘   │ └───────────────────┘│
│ ┌────────┐┌────────┐┌────────┐   │        북              │
│ │식수·식량 필요││약 필요││도움 필요│ │    □   ●  ■(내 차)  □   │
│ └────────┘└────────┘└────────┘   │      □       ●          │
└──────────────────────────────────┴────────────────────────────┘
```

- 세로 화면에서는 보내기 영역이 위, 받은 신호가 아래.
- 첫 화면은 3×3 같은 크기 칸 9개가 전부다: 보내지 않는 칸 둘(`주변 시설`, `저전력 모드`)과 보낼 수 있는 메시지 7개. 어느 메시지든 보내는 방식이 같으므로 더 크게 둘 칸이 없다. "다른 상황" 목록은 없다.
- 순서는 고정이다(`RescueMessage.OFFERED`): 주변 시설, 연료·전력 부족, 고립됨 / 추위·저체온, 저전력 모드, 응급 환자 / 식수·식량 필요, 약 필요, 도움 필요. 상황을 바꿔도 같은 자리에 있다. 맨 아랫줄은 "… 필요"로 이름을 맞췄다.
- 정체된 피난 행렬에서 옆 차에 부탁하거나 알릴 것만 남겼다. 식수와 식량은 한 칸이다.
- `주변 시설`은 보내지 않고 종류별 목록(대피소, 약국, 종합병원, 편의점)을 여는 칸이라 회색 바탕이다. P단이 아니어도 누를 수 있다(메시지 칸만 흐려진다).
- `도움 필요`는 SOS 아이콘을 쓰는 칸이다(신호 종류는 SOS 그대로). 무슨 일인지 알려 주지 않아 다른 메시지보다 정보가 적으므로, 맞는 메시지가 있으면 그것을 누르는 게 낫다. 불빛은 다른 위급 메시지와 같은 SOS 점멸이다.
- 칸에는 아이콘과 이름만 둔다.
- 나머지 메시지(고립됨, 침수, 가스·위험물, 노약자·어린이, 앞길 막힘, 모두 안전 등)는 보내지 않는다. 이전 버전이 보낸 신호는 계속 읽는다(`RescueMessage.RETIRED`).

## 4. 흐름

**보내기**
1. 메시지를 누른다.
2. 확인 화면이 뜬다(너비 1200dp, 줄 높이 120dp로 여유 있게): 메시지 이름, "함께 있는 사람" 수(− 3명 + 를 테두리 하나로 묶은 칸), 내 위치 함께 보내기 스위치. 길·대피소·구조대처럼 사람과 관계없는 메시지는 인원을 묻지 않는다.
   - 버튼 위에 한 줄: "누르면 차가 알아서 신호음을 내고 전조등을 깜빡여요". 고르는 항목이 아니라 곧 차가 할 일을 미리 알리는 말이다(갑자기 소리가 나서 놀라지 않게). "보내는 방법"이라는 이름은 사용자가 뭔가 해야 하는 것처럼 읽혀서 쓰지 않는다.
   - 무슨 메시지인지는 신호음 안에 데이터로 들어간다. 받는 차의 앱이 그 소리를 읽어 "응급 환자 3명 · 북동쪽 약 250m"로 띄운다. 불빛은 앱이 없는 사람에게 급한 정도만 알린다(위급 SOS, 도움 필요 1분에 6번). 그래서 이 한 줄은 대부분의 메시지에서 같다.
3. 아래 `보내기`를 누른다. 왼쪽 `취소`로 돌아갈 수 있다.
4. 보내는 중 화면: "소리로 알리는 중 2/3", "전조등 깜빡이는 중"을 줄마다 보여 주고, 아래에 `멈추기`.
5. 끝나면 "보냈어요"와 "근처 차량이 받으면 오른쪽에 표시돼요". `다시 보내기` / `처음으로`.
6. 내 신호를 다른 차량이 이어서 전달하면 보내기 영역 위에 회색 안내 줄이 뜬다.

**보낼 수 없을 때**
- 기어가 P가 아니면 메시지가 흐려지고, 맨 위 작은 줄이 "차를 세우고 기어를 P로 바꾸면 보낼 수 있어요"로 바뀐다. 같은 말을 메시지 아래에 다시 쓰지 않는다.
- 받기는 계속된다.

**받기**
- 새 신호(최근 10분 안, 아직 닫거나 본 적 없는 것)는 지도 위 상단에 알림으로 뜬다: 검은 띠 "새 신호 · N건 더 · 모두 보기", 아래 카드, `닫기` / `받았다고 알리기`. 닫으면 다음 새 신호가 뜬다. 앱을 다시 켰을 때 오래된 신호가 알림으로 뜨지 않는다.
- 위치가 있는 신호는 지도에 동그라미로 찍힌다(위급은 빨강). 누르면 같은 카드가 뜬다.
- 전체 목록은 머리말 `받은 신호 N`. 목록을 열면 모든 신호를 본 것으로 친다.
- 카드 한 장 = 신호 하나. 읽는 순서는 도우러 갈지 정하는 순서다: 제목 "응급 환자  2명"(가장 크게) → 위치 "북동쪽 약 250m"(핀 아이콘, 굵게) → 전달 경로 "가까운 차량" 또는 "차량 2대를 거쳐 전달"(작게). 오른쪽 위 "방금 / 3분 전".
- 인원은 "·" 없이 두 칸 띄우고 옅은 색·보통 굵기로 쓴다. "화재·연기"처럼 이름 안에 이미 "·"가 있어서다.
- 구조 서버에서 받은 카드는 경로를 적지 않고, 응답 버튼도 없다. 두 대 이상이 같은 요청을 알렸을 때만 "차량 3대가 알림"을 붙인다.
- 내 차가 이전에 보낸 요청은 서버에서 다시 받아도 목록에 넣지 않는다.
- 카드는 모두 흰 바탕에 테두리. 위급한 신호는 아이콘만 빨강이라 바로 골라낼 수 있다.
- `받았다고 알리기`를 누르면 상대에게 응답 신호(분당 3회 점멸 + 소리)를 보낸다. 누른 뒤에는 "응답했어요"로 바뀐다.
- 같은 신호를 여러 번 받아도 카드는 하나만 둔다.
- 신호가 없으면 목록에 "아직 받은 신호가 없어요 · 주변 차량의 신호를 듣고 있어요 · 창문을 조금 열면 더 멀리서도 들려요".
- 듣기가 꺼져 있으면 머리말 작은 줄에 빨강 "듣기 꺼짐". 켜고 끄기는 설정에서 한다.

**주변 지도** (오른쪽)
- 내 차를 가운데 두고 북쪽이 위. 가까운 대피소 8곳(네모, 테두리)과 위치가 있는 받은 신호(동그라미, 위급은 빨강)를 실제 방향과 거리에 찍는다.
- 지도 타일을 받아 쓰지 않고 앱이 직접 그린다. 통신이 끊겨도 그대로 보인다. 길 단위 안내는 차 내비게이션 몫이다.
- 거리는 제곱근 눈금이다: 가까운 것이 더 넓게 펼쳐진다. 범례(네모·동그라미 설명, 원의 거리)는 두지 않는다. 거리는 표시를 누르면 나온다. 바깥 원은 가장 먼 표시 대상에 맞춰 100m~10km에서 고른다.
- 겹치는 표시는 주변 빈자리로 옮기고, 지도 밖으로 밀지 않는다. 대피소 이름은 겹치지 않는 곳에만 적고, 나머지는 누르면 보인다.
- 지도 아래 한 줄: 가장 가까운 대피소 이름과 방향·거리. 누르면 상세(방향·거리, 종류, 수용 인원, 주소).
- 대피소 상세 아래 버튼은 `닫기` / `길 안내`(검정). `길 안내`는 대피소 좌표와 이름을 차 내비(NaviHelper)에 목적지로 넘기고, 화면은 차 내비로 바뀐다. 시작하지 못하면 버튼 위에 빨강으로 "차 내비로 길 안내를 시작하지 못했어요".
- 오른쪽 위 `대피소 목록 ›`: 주변 시설 화면을 대피소 종류로 연다.
- 대피소 데이터: 앱에 든 전국 민방위대피소(반경 10km 안 가까운 80곳) + 통신이 될 때 서버에서 받은 대피소. 같은 곳은 하나만.
- 위치 상태별 표시:
  - GPS 위치가 2분 넘게 안 바뀌면 제목 아래 빨강 "5분 전 위치 기준 · GPS가 잡히지 않아요"와 `지역 고르기 ›`.
  - 위치가 1km 넘게, 시속 250km보다 빠르게 튀면 그 위치를 쓰지 않고 빨간 테두리 질문: "위치가 갑자기 약 316km 바뀌었어요 · GPS 교란일 수 있어요" `아니요, 그대로 두기`(검정) / `네, 새 위치로`. 머리말에 빨강 "GPS 이상".
  - "그대로 두기" 뒤 같은 곳(2km 안)에서 오는 위치는 다시 묻지 않고 "GPS 신호가 이상해서 새 위치를 쓰지 않고 있어요". 믿을 만한 위치가 다시 오면 사라진다.
  - 위치가 아예 없으면 "내 위치를 찾고 있어요 · GPS가 잡히지 않으면 지금 있는 지역을 골라 주세요"와 `지역 고르기`. 머리말에 빨강 "위치 못 잡음".
  - 지역을 고르면 제목이 "강남구 대피소", 그 지역 대피소를 주소 순으로 보여 준다("위치를 못 잡아 고른 지역이에요 · 거리는 알 수 없어요"). 믿을 만한 GPS 위치가 다시 오면 지도로 돌아간다.
- 지역 고르기: 시·도 → 시·군·구 두 단계, 같은 크기 틀, 둘째 단계에 `이전` / `닫기`. 시·군·구가 없는 세종은 시·도만 고른다.
- 마지막 위치는 앱을 다시 켜도 기억한다. 보내는 메시지에는 10분 안의 위치나, 그 위치를 잡은 뒤로 계속 P단인 경우의 위치만 붙인다. 확인 화면에 "함께 보내요 (30분 전 위치, 그 뒤로 정차 중)" 또는 "마지막 위치가 오래돼 위치 없이 보내요".

**행동요령** (오른쪽 위 `행동요령`)
- 버튼을 누르면 "지금 어떤 상황인가요?"가 뜨고 상황 9개를 3×3 큰 칸으로 고른다: 피난 중(경보 없음), 경계경보, 공습경보, 화생방경보, 대설·한파, 호우·침수, 지진, 산불, 태풍·강풍. 고르면 그 상황의 차 안 행동요령이 뜬다. 고른 상황은 검정으로 채운다. 제목 아래 설명 줄은 두지 않는다.
- 행동요령 문장은 행정안전부 국민행동요령(민방공 경보, 비상사태, 통신 장애, 화학사고)에서 그대로 나눠 담았다. 출처에 없는 말은 넣지 않았다.
- 공습경보는 등화관제를 자동으로 켠다. 등화관제 중에는 불빛 신호를 쓰지 않고, 차가 켜져 있던 전조등·상향등·미등·안개등·실내등·독서등·앰비언트 조명을 끈다. 등화관제가 끝나면 원래대로 켠다.
- 화생방경보는 차가 창문을 모두 닫고 공조를 내기순환으로 바꾼 뒤 끈다. 단계에서 벗어나면 공조만 원래대로 돌리고 창문은 닫힌 채로 둔다. 난방 아끼기를 쓰는 중이면 공조는 끄지 않고 내기순환만 유지한다.
- 차를 바꾸는 일은 P단에서만 한다. P단이 아닐 때 단계를 고르면 P단이 된 뒤에 실행한다.
- 차가 한 일은 행동요령 제목 아래 한 줄로 알린다: "차 불을 모두 껐어요", "창문을 닫고 바깥 공기를 막았어요". 차량이 거부하면 빨강으로 "차 불을 다 끄지 못했어요. 직접 꺼 주세요", "창문이나 공조를 바꾸지 못했어요. 직접 닫아 주세요". 차량에 해당 기능이 없으면 줄을 넣지 않는다.
- 등화관제 중에 P단을 벗어나면 차량이 조명 제어를 거부해 불을 다시 켤 수 없다. 이때 음성으로 "차 불이 꺼져 있어요. 출발하기 전에 전조등을 직접 켜 주세요."라고 한 번 알리고, 꺼 둔 조명은 기억해 두었다가 등화관제가 끝난 뒤 P단에서 다시 켠다.
- 재난문자에 "공습"·"미사일"·"경계경보"·"화생방"이 있으면 그 단계를, 서버가 대설·한파, 호우·침수, 지진, 산불, 태풍으로 분류한 문자는 그 상황을 제안한다. "훈련" 문자는 제안하지 않는다(`DisasterGuides.stageOf`).
- 산불도 화생방경보처럼 창문을 닫고 바깥 공기를 막는다(행동요령의 "창문과 문을 꼭 닫고"). 대피소는 전시 네 단계에서 민방위대피소, 지진에서 옥외대피장소, 대설·한파에서 한파쉼터를 먼저 보여 준다.
- 첫 화면에는 행동요령을 따로 붙이지 않는다. 버튼 이름은 상황을 골라도 `행동요령` 그대로다. 고른 상황은 상황 목록에서 검정 칸으로 보인다.
- 상황 목록과 행동요령은 같은 크기의 틀(화면 높이의 90%)을 쓴다. 상황마다 글 길이가 달라도 틀 크기는 바뀌지 않는다.
- 행동요령은 왼쪽에 "이렇게 하세요"(번호), 오른쪽에 "하지 마세요"(✕)와 "차에서 조심할 점"(!)을 둔다. 오른쪽에 둘 것이 없으면 한 단으로 쓴다. 글자는 다른 화면보다 한 단계 크게(30sp) 쓴다. 가장 긴 상황도 스크롤 없이 들어간다.
- 출처는 맨 아래 한 줄에 기관 이름만 적는다: "출처: 행정안전부, 미국 기상청". 자료 제목·날짜·종류(언론 보도 등)와 문장마다 붙이던 "(해외)"는 화면에 넣지 않는다. 상세 출처는 코드(`DisasterGuide.kt`)에 남긴다.
- 아래 버튼은 `이전`(상황 목록으로) / `닫기`. 재난문자에서 바로 열었을 때는 돌아갈 목록이 없으므로 `닫기`만 둔다.
- 다른 단계로 바꾸면 공습경보가 켠 등화관제는 꺼지고 차 불이 원래대로 돌아온다.

**머리말** (화면 위 왼쪽)
- 왼쪽에는 상태만, 오른쪽에는 누르는 버튼만 둔다. 버튼(받은 신호 N, 행동요령, 설정)은 모두 같은 높이다. 가로 화면에서는 세 버튼의 너비도 같고, 버튼 줄이 아래 주변 지도 칸과 같은 너비를 차지해 왼쪽·오른쪽 끝이 세로로 맞는다.
- 첫 줄(크게): "어떤 상황인지 알려주세요". 둘째 줄(작게): 보낼 수 있는지 — "가까이 위치한 차량에 신호를 보낼 수 있어요", "차를 세우고 기어를 P로 바꾸면 보낼 수 있어요", "차 상태를 확인하고 있어요", "차량에 연결하는 중".
- 둘째 줄에는 평소와 다른 것만 덧붙인다: 연습 모드, 통신 끊김(빨강), 등화관제 중·외기 차단 중(검정 굵게), 에너지 부족 "배터리 8% 남음"(빨강). 통신이 잘 되거나 배터리가 넉넉한 것은 알릴 일이 아니라 적지 않는다.
- 버틸 수 있는 시간은 가정(바깥 온도, 기본 전력)에 따라 크게 달라지는 추정이라 여기 두지 않고, 판단이 필요한 난방 아끼기 줄에만 둔다.
- 버틸 시간이 6시간 미만이면 보내기 영역에 `불빛 끄기` 안내가 뜬다.

**받은 신호의 위치**
- 둘째 줄에 "가까운 차량 · 북동쪽 약 300m". 내 위치를 모르면 "위치 받음".
- 확인 화면에 "내 위치: 함께 보내요 (약 40m 범위)"와 끄기 스위치.

**저전력 모드** (첫 화면 가운데 칸. 예전의 맨 아래 "난방 아끼며 오래 버티기" 줄을 대신한다)
- 칸은 `주변 시설`처럼 회색이고, 켜져 있는 동안 검정으로 채운다. 전기차 배터리 값과 제어할 수 있는 히터가 없거나 P단이 아니면 글자가 회색이고 눌리지 않는다. 켜져 있으면 머리말 둘째 줄에 "저전력 모드 중"이 붙는다.
- 지금은 난방 전력을 줄이는 기능이다. 이름은 앞으로 조명·기타 절전을 묶을 수 있게 넓게 잡았다.
- 화면: "함께 있는 사람" 수(좌석 감지 값이 기본), 두 가지 방법 중 하나를 고른다.
  - `아껴 쓰기`: 실내 12~16도, 앉은 자리 열선. 가장 오래 버틴다.
  - `덜 춥게`: 실내 18도 유지. 어르신이나 아이가 있을 때.
  - 방법마다 버틸 수 있는 시간을 오른쪽에 크게 보여 준다. 지금처럼 틀 때와의 비교는 첫 화면 줄에 이미 있으므로 화면 안에 다시 쓰지 않는다.
- "시작하면 이렇게 해요" 세 줄: 바깥 공기 넣는 주기(화학사고·방사능·산불 모드에서는 "바깥 공기는 들이지 않아요"), 옷·담요 안내, 멈추는 방법.
- 아래 `취소` / `시작하기`. 시작하면 같은 화면이 "난방을 아끼는 중"으로 바뀌고 지금 상태("난방하는 중 · 실내 약 14도")와 버틸 수 있는 시간을 보여 준다. 아래 `닫기` / `그만하고 원래 난방으로`.
- 켜져 있는 동안 첫 화면의 줄은 회색 바탕 "난방을 아끼는 중"으로 바뀐다.
- 기어를 P에서 바꾸면 자동으로 멈추고 줄에 "기어를 바꿔서 난방을 원래대로 돌려놓았어요"를 보여 준다.

**휴대폰으로 전달 (QR)** (보내는 중·보낸 뒤 화면의 `앱이 없는 사람에게 QR로 전달`)
- 구조 서버가 설정된 빌드에서만 보인다.
- 왼쪽에 QR 코드(밤 화면에서도 흰 바탕에 검정), 오른쪽에 세 단계 안내와 메시지·인원·위치 좌표. 좌표는 전화로 불러 줄 수 있게 숫자로 적는다.

**줄바꿈**
- 여러 줄 문장은 낱말 중간에서 끊지 않고 띄어쓰기에서만 줄을 바꾼다.
- 여러 줄이 될 수 있는 문장은 줄 간격을 글자 크기의 1.35배로 지정한다(`Type.lines`). 기본 줄 간격(24sp)은 큰 글자보다 작아서 줄이 겹친다.

**아이콘 색**
- 보내는 쪽(첫 화면, 확인 화면)의 아이콘은 모두 검정이다. 누르는 사람에게 급한 정도를 색으로 다시 알릴 필요가 없다.
- 받는 쪽은 위급한 신호만 빨강, 나머지는 검정이다.

**누를 수 없는 버튼**
- 채운 버튼은 회색 바탕에 회색 글자, 테두리 버튼은 글자만 회색. 투명도 레이어로 흐리게 하지 않는다(다시 켤 때 버튼이 안 그려지는 문제가 있었다).

**주변 시설** (첫 화면 첫 칸 `주변 시설`, 지도 오른쪽 위 `대피소 목록 ›`)
- 설정과 같은 구조: 왼쪽에 종류(대피소, 약국, 종합병원, 편의점. 고른 것은 검정으로 채움)와 맨 아래 `닫기`, 오른쪽에 그 종류의 가까운 곳 20개. 틀 크기는 너비 1400dp, 화면 높이의 80%로 고정한다.
- 한 줄에 이름, 주소, 방향·거리("북동쪽 약 50m"). 누르면 상세(방향·거리, 종류, 수용 인원, 주소)가 뜨고 아래 버튼은 `이전` / `닫기` / `길 안내`.
- 대피소는 민방위대피소를 거리와 상관없이 먼저 보여 준다.
- 약국·종합병원·편의점은 앱에 든 전국 목록에서 찾는다. 통신이 없어도 된다. 문을 열었는지는 알 수 없다.
- 위치를 못 잡아 지역을 골랐을 때는 그 시·군·구의 곳을 주소 순으로 60개까지 보여 주고 거리는 적지 않는다. 위치도 지역도 없으면 "위치를 아직 몰라요. 주변 지도에서 지역을 고르면 그 지역 시설을 보여 드려요".
- 데이터가 없는 종류(주유소, 충전소, 급수시설)는 칸을 만들지 않는다. 데이터를 넣을 때 종류를 추가한다.
- 출처는 설정 > 차량·서버의 "데이터 출처" 한 줄에 기관 이름으로 적는다.

**설정** (오른쪽 위 `설정`)
- Pleos 설정 앱과 같은 구조: 왼쪽에 항목(고른 것은 검정으로 채움), 오른쪽에 그 항목의 스위치. 왼쪽 맨 아래 `닫기`.
- 틀 크기는 너비 1300dp, 화면 높이의 72%로 고정한다. 항목을 바꿔도 크기가 그대로이고, 화면 세로를 꽉 채우지 않는다.
- 스위치 설명은 한 줄로 쓴다.
- 보내는 방법: 소리, 사람이 듣는 SOS 소리, 전조등 깜빡임, 깜빡일 위치(앞 / 뒤 / 앞뒤), 등화관제, 내 위치 함께 보내기
- 받은 신호: 주변 신호 듣기, 이어서 전달하기, 음성으로 알려 주기, 시연용 "다른 차 신호 받아 보기", (연습 모드일 때) 기어 바꾸기
- 차량·서버: 구조 서버 상태와 보관 중인 요청 건수, 차량 연결 상태, 제어할 수 있는 불빛
