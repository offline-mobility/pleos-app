# 화면 설계

대상: 재난 현장에서 차 안에 있는 40~60대를 포함한 운전자·동승자. 긴장한 상태에서 처음 보는 화면을 다뤄야 한다.

## 1. 원칙

| 원칙 | 적용 |
|---|---|
| 한 번 보고 알 수 있게 | 화면마다 할 일은 하나. 첫 화면은 "보내기", 오른쪽은 "받은 신호" |
| 누를 것은 크게 | 주 버튼 높이 96dp(약 15mm), 보조 버튼 72dp 이상. 버튼 사이 간격 16dp 이상 |
| 글자는 크게 | 제목 34sp, 본문 24sp, 보조 정보 20sp 이상. 160dpi 차량 화면에서 제목 높이 약 5mm |
| 쉬운 말 | "송신·중계·SNR·홉" 같은 말을 쓰지 않는다. "보내기, 이어서 전달, 가까운 차량" |
| 색은 의미가 있을 때만 | 빨강 위급, 주황 도움 필요, 초록 안전·좋은 소식, 파랑 내 행동. 나머지는 무채색 |
| 색만으로 전달하지 않기 | 모든 메시지에 아이콘과 글자를 함께 붙인다 |
| 실수해도 되돌릴 수 있게 | 메시지를 누르면 바로 보내지 않고 확인 화면을 띄운다. 보내는 중에는 언제든 멈출 수 있다 |
| 행동 버튼은 아래 | 확인·멈추기·닫기 버튼은 화면 아래쪽에 둔다 |

## 2. 색

밝은 화면이 기본이고, 시스템이 야간 모드면 어두운 화면을 쓴다.

| 토큰 | 밝은 화면 | 어두운 화면 | 쓰임 |
|---|---|---|---|
| page | `#F7F8FA` | `#111317` | 바탕 |
| canvas | `#FFFFFF` | `#1B1E24` | 카드, 시트 |
| surface | `#F1F3F5` | `#252931` | 상태 줄, 낮은 면 |
| line | `#E3E6EB` | `#323741` | 테두리 |
| ink | `#17191E` | `#F2F4F7` | 제목 |
| body | `#474C55` | `#C9CED6` | 본문 |
| mute | `#8B919C` | `#8B919C` | 시간, 보조 정보 |
| accent | `#2B5CE6` | `#5B83F0` | 선택, 내 행동 |
| urgent | `#E5484D` | `#F2555A` | 위급 메시지 |
| help | `#E8890C` | `#F09A2A` | 도움 필요, 주의 |
| safe | `#2F9A6A` | `#3DB07D` | 안전, 좋은 소식, 완료 |

그라데이션, 글로우, 그림자 장식은 쓰지 않는다.

## 3. 화면 구성 (가로)

```
┌───────────────────────────────────────────────────────────────┐
│ ● 정차 중 · 신호를 보낼 수 있어요   [대피소] [행동요령] [설정] │
├──────────────────────────────────┬────────────────────────────┤
│ ┌──────────────────────────────┐ │ 주변에서 온 신호        ● 듣는 중│
│ │ [SOS]  긴급 구조 요청          │ │ ┌────────────────────────┐ │
│ │        지금 바로 도움이 필요해요 │ │ │[+] 응급 환자  2명    방금 │ │
│ └──────────────────────────────┘ │ │    가까운 차량            │ │
│ ┌────────┐┌────────┐┌────────┐   │ │          [받았어요 보내기] │ │
│ │응급 환자││ 고립됨 ││화재·연기│   │ └────────────────────────┘ │
│ └────────┘└────────┘└────────┘   │ ┌────────────────────────┐ │
│ ┌────────┐┌────────┐┌────────┐   │ │[집] 대피소 있음     3분 전│ │
│ │  침수  ││식수 필요││다른 메시지│   │ │    차량 2대를 거쳐 전달   │ │
│ └────────┘└────────┘└────────┘   │ └────────────────────────┘ │
│ [온도계] 난방 아끼며 오래 버티기  열기 › │                            │
└──────────────────────────────────┴────────────────────────────┘
```

- 세로 화면에서는 보내기 영역이 위, 받은 신호가 아래.
- 긴급 구조 요청은 가장 크고 유일하게 빨간 면을 쓴다. 가장 급한 사람이 가장 빨리 찾는다.
- 첫 화면의 메시지는 위급한 것 다섯 개로 줄였다. 나머지 아홉 개는 "다른 메시지"에서 종류별로 고른다.

## 4. 흐름

**보내기**
1. 메시지를 누른다.
2. 확인 화면이 뜬다: 메시지 이름과 뜻, "함께 있는 사람" 수(− / +), 보내는 방법("소리 3번 + 전조등 SOS 깜빡임"). 길·대피소·구조대처럼 사람과 관계없는 메시지는 인원을 묻지 않는다.
3. 아래 `보내기`를 누른다. 왼쪽 `취소`로 돌아갈 수 있다.
4. 보내는 중 화면: "소리로 알리는 중 2/3", "전조등 깜빡이는 중"을 줄마다 보여 주고, 아래에 `멈추기`.
5. 끝나면 "보냈어요"와 "근처 차량이 받으면 오른쪽에 표시돼요". `다시 보내기` / `처음으로`.
6. 내 신호를 다른 차량이 이어서 전달하면 보내기 영역 위에 초록 안내가 뜬다.

**보낼 수 없을 때**
- 기어가 P가 아니면 메시지가 흐려지고, 아래에 "차를 세우고 기어를 P로 바꾸면 보낼 수 있어요".
- 받기는 계속된다.

**받기**
- 카드 한 장 = 신호 하나. 읽는 순서는 도우러 갈지 정하는 순서다: 제목 "응급 환자  2명"(가장 크게) → 위치 "북동쪽 약 250m"(핀 아이콘, 굵게) → 전달 경로 "가까운 차량" 또는 "차량 2대를 거쳐 전달"(작게). 오른쪽 위 "방금 / 3분 전".
- 인원은 "·" 없이 두 칸 띄우고 옅은 색·보통 굵기로 쓴다. "화재·연기"처럼 이름 안에 이미 "·"가 있어서다.
- 구조 서버에서 받은 카드는 경로를 적지 않는다. 두 대 이상이 같은 요청을 알렸을 때만 "차량 3대가 알림"을 붙인다.
- 응답 버튼은 카드 글 너비에 맞춰 한 줄 전체를 쓴다.
- 내 차가 이전에 보낸 요청은 서버에서 다시 받아도 목록에 넣지 않는다.
- 위급 메시지 카드는 연한 빨강 바탕.
- `받았어요 보내기`를 누르면 상대에게 응답 신호(분당 3회 점멸 + 소리)를 보낸다. 누른 뒤에는 "응답했어요"로 바뀐다.
- 같은 신호를 여러 번 받아도 카드는 하나만 둔다.
- 신호가 없으면 "아직 받은 신호가 없어요 · 주변 차량의 신호를 듣고 있어요 · 창문을 조금 열면 더 멀리서도 들려요".

**행동요령** (오른쪽 위 `행동요령`, 상황을 고른 뒤에는 `지진 행동요령`)
- 버튼을 누르면 13가지 상황 목록이 뜨고, 하나를 고르면 그 상황의 행동요령이 뜬다. 일반 재난도 같다.
- 첫 화면에는 행동요령을 따로 붙이지 않는다. 지금 상황은 버튼 이름으로 보인다.
- 상황 목록과 행동요령은 같은 크기의 틀(화면 높이의 90%)을 쓴다. 상황마다 글 길이가 달라도 틀 크기는 바뀌지 않는다.
- 행동요령은 왼쪽에 "이렇게 하세요"(번호), 오른쪽에 "하지 마세요"(✕)와 "차에서 조심할 점"(!)을 둔다. 오른쪽에 둘 것이 없으면 한 단으로 쓴다. 글자는 다른 화면보다 한 단계 크게(30sp) 쓴다. 가장 긴 상황도 스크롤 없이 들어간다.
- 출처는 맨 아래 한 줄에 기관 이름만 적는다: "출처: 행정안전부, 미국 기상청". 자료 제목·날짜·종류(언론 보도 등)와 문장마다 붙이던 "(해외)"는 화면에 넣지 않는다. 상세 출처는 코드(`DisasterGuide.kt`)에 남긴다.
- 아래 버튼은 `이전`(상황 목록으로) / `닫기`. 재난문자에서 바로 열었을 때는 돌아갈 목록이 없으므로 `닫기`만 둔다.
- 메시지 5개가 상황에 맞게 바뀐다. 공습은 등화관제를 자동으로 켜고, 다른 상황으로 바꾸면 끈다.

**상태 줄** (화면 위 왼쪽)
- 왼쪽에는 상태만, 오른쪽에는 누르는 버튼만 둔다. 버튼(대피소, 상황, 설정)은 모두 같은 높이다.
- 첫 줄: "정차 중 · 신호를 보낼 수 있어요". 둘째 줄에 상태를 한 줄로 잇는다: "통신 연결됨 · 배터리 100%". 통신 끊김, 등화관제 중, 연습 모드도 이 줄에 뜬다. 색은 통신 연결(초록), 끊김·등화관제·에너지 부족(주황)에만 쓴다.
- 상태 줄에는 차가 알려 주는 값만 쓴다. 버틸 수 있는 시간은 가정(바깥 온도, 기본 전력)에 따라 크게 달라지는 추정이라 여기 두지 않고, 판단이 필요한 난방 아끼기 줄에만 둔다.
- 6시간 미만이면 주황으로 바뀌고, 보내기 영역에 `불빛 끄기` 안내가 뜬다.

**받은 신호의 위치**
- 둘째 줄에 "가까운 차량 · 북동쪽 약 300m". 내 위치를 모르면 "위치 받음".
- 확인 화면에 "내 위치: 함께 보내요 (약 40m 범위)"와 끄기 스위치.

**난방 아끼며 오래 버티기** (보내기 영역 맨 아래 줄)
- 전기차이고 차량이 히터 제어를 허용하며 P단일 때만 보인다. 폭염 모드에서는 보이지 않는다.
- 줄에 "지금처럼 틀면 약 28시간 · 아껴 쓰면 약 32시간 (추정)"을 보여 준다. 누르면 화면이 열린다.
- 화면: "함께 있는 사람" 수(좌석 감지 값이 기본), 두 가지 방법 중 하나를 고른다.
  - `아껴 쓰기`: 실내 12~16도, 앉은 자리 열선. 가장 오래 버틴다.
  - `덜 춥게`: 실내 18도 유지. 어르신이나 아이가 있을 때.
  - 방법마다 버틸 수 있는 시간을 오른쪽에 크게 보여 준다. 지금처럼 틀 때와의 비교는 첫 화면 줄에 이미 있으므로 화면 안에 다시 쓰지 않는다.
- "시작하면 이렇게 해요" 세 줄: 바깥 공기 넣는 주기(화학사고·방사능·산불 모드에서는 "바깥 공기는 들이지 않아요"), 옷·담요 안내, 멈추는 방법.
- 아래 `취소` / `시작하기`. 시작하면 같은 화면이 "난방을 아끼는 중"으로 바뀌고 지금 상태("난방하는 중 · 실내 약 14도")와 버틸 수 있는 시간을 보여 준다. 아래 `닫기` / `그만하고 원래 난방으로`.
- 켜져 있는 동안 첫 화면의 줄은 연한 초록 바탕 "난방을 아끼는 중"으로 바뀐다.
- 기어를 P에서 바꾸면 자동으로 멈추고 줄에 "기어를 바꿔서 난방을 원래대로 돌려놓았어요"를 보여 준다.

**휴대폰으로 전달 (QR)** (보내는 중·보낸 뒤 화면의 `앱이 없는 사람에게 QR로 전달`)
- 구조 서버가 설정된 빌드에서만 보인다.
- 왼쪽에 QR 코드(밤 화면에서도 흰 바탕에 검정), 오른쪽에 세 단계 안내와 메시지·인원·위치 좌표. 좌표는 전화로 불러 줄 수 있게 숫자로 적는다.

**다른 메시지**
- 아이콘을 글 왼쪽에 둔 낮은 칸으로 13가지를 한 화면에 모두 보여 준다. 스크롤하지 않는다.

**줄바꿈**
- 여러 줄 문장은 낱말 중간에서 끊지 않고 띄어쓰기에서만 줄을 바꾼다.
- 여러 줄이 될 수 있는 문장은 줄 간격을 글자 크기의 1.35배로 지정한다(`Type.lines`). 기본 줄 간격(24sp)은 큰 글자보다 작아서 줄이 겹친다.

**아이콘 색**
- 아이콘 색은 사물의 색이 아니라 급한 정도다(빨강 위급, 주황 도움 필요, 초록 안전). 보내는 화면과 받는 화면, 구조 상황판이 같은 색을 쓴다.

**누를 수 없는 버튼**
- 색을 옅게 해서 보여 준다. 채운 버튼은 바탕이 옅어지고 글자는 그대로, 테두리 버튼은 글자가 옅어진다.

**대피소** (오른쪽 위 `대피소`, 받아 둔 대피소가 있을 때만)
- 가까운 여섯 곳을 이름, 종류, 수용 인원(민방위대피소는 "약 N명"), 주소, 방향·거리와 함께 보여 준다.
- 공습·지진·대설·한파·폭염 모드에서는 그 상황에 맞는 종류를 거리와 상관없이 먼저 보여 주고, 위에 "‘지진’ 상황에 맞는 곳을 먼저 보여 드려요"를 적는다.

**설정** (오른쪽 위 `설정`)
- 보내는 방법: 소리, 사람이 듣는 SOS 소리, 전조등 깜빡임, 깜빡일 위치(앞 / 뒤 / 앞뒤), 내 위치 함께 보내기
- 등화관제: 불빛 없이 소리로만 보내기
- 받은 신호 이어서 전달하기, 음성으로 알려 주기
- 구조기관 전달: 보관 중인 구조 요청 건수, 통신 상태
- 시연: 다른 차 신호 받아 보기, (연습 모드일 때) 기어 바꾸기
- 차량 정보: 차량 연결 상태, 제어할 수 있는 조명

## 5. 문구

| 메시지 | 제목 | 설명 |
|---|---|---|
| SOS | 긴급 구조 요청 | 지금 바로 도움이 필요해요 |
| MEDICAL | 응급 환자 | 다친 사람이 있어요 |
| TRAPPED | 고립됨 | 차가 움직일 수 없어요 |
| FIRE | 화재·연기 | 불이 났거나 연기가 나요 |
| FLOOD | 침수 | 물이 차오르고 있어요 |
| HAZARD | 가스·위험물 | 가스나 위험한 물질이 새요 |
| VULNERABLE | 노약자·어린이 | 어르신이나 아이가 함께 있어요 |
| WATER | 식수 필요 | 마실 물이 없어요 |
| POWER | 연료·전력 부족 | 기름이나 배터리가 떨어져 가요 |
| ROAD_BLOCKED | 앞길 막힘 | 이쪽으로는 갈 수 없어요 |
| ROUTE_CLEAR | 지나갈 수 있음 | 이 길로 이동할 수 있어요 |
| SHELTER | 대피소 있음 | 근처에 대피소가 있어요 |
| RESCUE_TEAM | 구조대 접근 | 구조대가 오고 있어요 |
| ALL_SAFE | 모두 안전 | 우리 차 사람들은 괜찮아요 |
| ACK | 잘 받았어요 | 신호를 받았다는 응답 |
