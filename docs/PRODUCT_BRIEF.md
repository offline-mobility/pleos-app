## 핵심 사용 시나리오

1. 사용자가 차량에 탑승한다.
2. 앱이 필요한 차량 Capability를 확인한다.
3. 차량 상태와 이동 맥락을 바탕으로 핵심 기능을 제공한다.
4. 주행 상태에 따라 화면과 입력 기능을 안전하게 제한한다.

## SDK 매핑

| 기능 | 후보 SDK | API 또는 데이터 | 권한 | 제공 상태 |
|---|---|---|---|---|
| 차량 상태 | Vehicle SDK 2.3.2 | 확정 필요 | 최소 권한만 선언 | Vehicle State 사용 가능 |
| 길 안내 | NaviHelper 3.0.5 | 확정 필요 | Navi 권한 | 사용 가능 |
| 위치 | FusedLocation 1.1.3 | 확정 필요 | FUSED_LOCATION | 포털 확인 필요 |
| 음성 입력 | SpeechToText 3.3.1 | 확정 필요 | 마이크 및 SDK 권한 | 포털 확인 필요 |
| 음성 출력 | TextToSpeech 3.3.1 | 확정 필요 | SDK 권한 | 포털 확인 필요 |

## MVP 완료 기준

- Pleos Connect Emulator에서 앱이 실행된다.
- 핵심 차량 데이터가 Virtual Console 변화에 반응한다.
- 주행 중 UX 제한이 적용된다.
- 실패·미지원·권한 부족 상태가 화면에 표시된다.
- 시연 영상과 APK를 재현 가능한 방식으로 생성할 수 있다.
